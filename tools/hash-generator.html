Flag Hash Generator

Authoring tool — not linked from site navigation. Use this to mint new challenge flags. Every flag needs a random suffix for entropy: an unsalted SHA-256 hash ships in assets/js/data/*.js in plain sight, so a guessable flag like flag{password} is crackable offline in microseconds. The random suffix is what makes that infeasible — it can only be read off the solved artifact (the stego image, the decoded ciphertext, the sandboxed page's DOM, etc.), never guessed from a dictionary.
